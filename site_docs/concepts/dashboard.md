# The dashboard

!!! info "About this page"
    This page is the repository's [`docs/DASHBOARD_GUIDE.md`](repo:docs/DASHBOARD_GUIDE.md),
    included when the site is built; the same file is the dashboard's **Guide** page. On this
    site, the **Try it** links and the links to dashboard pages open the
    [hosted dashboard](https://midfreq-dashboard-123943780205.asia-southeast1.run.app) with the
    example's settings filled in; a run starts only when its button is pressed. The hosted
    dashboard is private: visitors sign in with Google, and access is by invitation. Every view
    also works on a [local install](#running-the-dashboard-locally).
